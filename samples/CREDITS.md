## Notes

- The source page of each Wikimedia Commons file was not recorded. The content is public domain, so no attribution is required, but credit to Wikimedia Commons and its contributors is given here.
- If you hold rights to any of these files and believe it shouldn't be here, please open an issue — the file will be removed.
- Your own categories are not part of the repository: keep them outside it, or in a `Categories/` folder in the project folder (ignored by git).
